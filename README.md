# 2026年米国中間選挙 — 中間選挙で変わる権力

[公開サイト](https://guchio2366-dev.github.io/us-midterms-2026/)では、2026年中間選挙を「どの議席が動くか」だけでなく、「結果がトランプ大統領の権限をどこまで制約するか」までつないで表示します。上院35選挙、下院435選挙区、議会権限、8つの争点、50州の地域背景を一つの静的Webアプリに収録しています。

> データ基準日：2026-09-09。事実、情勢評価、利用者の仮定を分離して表示します。デラウェアは9月15日の予備選前、ロードアイランドは9月9日の開票確定前のスナップショットです。

## 画面の流れ

1. **ニュース**：出典付きイベントを10件ずつ枠内で読み、11件目以降はページを切り替えます。カードの詳細は主画面を離れないパネルで開きます。
2. **権限**：ニュース直下の表をタイトルで開閉し、行のボタンから必要票をシミュレーションへ渡します。
3. **シミュレーション**：同じ上院地図を「権限から逆算」「現在の選挙情勢」「投票前の議席構成」で切り替えます。
4. **出典**：事実・評価・仮定と、それぞれの対象時点を確認します。

「初めて開いた方へ」と「8つの論点から選挙を見る」はヘッダーの独立パネルです。論点の州別レポートと自動経路の係数は調査中で、`src/data/content.ts` の差し替え境界に置いています。

## 重要な読み方

- **事実**：公式名簿、選挙当局、Census、FEC、BEA、USDAなどの値です。
- **評価**：上院はSabato's Crystal Ball、下院は270toWinの6機関合意分類です。勝率や確定結果ではありません。
- **仮定**：上院・下院シミュレーションで利用者が選ぶ結果です。予測ではありません。
- **地域指標**：政策への曝露や地域背景です。人口、産業、生産量、過去得票だけから投票理由や因果を断定しません。

大豆ケースでは、中国向け輸出が2025年10月〜2026年7月に1,235.6万トン（前年同期比42.8%減）で、同期間の全輸出の33.6%だったことを示します。生産上位10州のうち8州でTrumpが2024年に勝利し、7州で2026年上院選があり、そのうちOHとIAがToss Up／Leanです。これは「対中強硬策が支持された州」と「輸出減への曝露」が同時に存在することを示しますが、政権支持・不支持の因果を直接証明するものではありません。

## 議席数と権限の要点

- 下院は全435議席改選。通常の全員在席時、多数派は218。
- 上院は通常33＋特別2の一意な35議席が対象。残る65議席は今回の選挙では動きません。
- 上院運営多数派は51、または50＋副大統領の決裁票。通常法案の討論終結は原則60。
- 指名承認は上院の単純多数。条約同意と弾劾有罪は出席上院議員の3分の2。
- 下院は弾劾訴追を出席投票者の過半数で行えますが、罷免には上院の3分の2が必要。
- 大統領拒否権を覆すには両院それぞれ出席議員の3分の2。全員出席なら下院290、上院67。

## データと設計

- `src/data/data.ts`：州、上院100議席・35選挙、50州プロフィール、年表、出典レジストリ
- `src/data/senate-races.ts`：上院候補者、予備選状態、統一情勢
- `src/data/civics.ts`：議会権限8項目、論点8分類
- `src/data/state-context.ts`：人口、2024年得票、産業、大豆、対中輸出
- `src/data/house.ts`：下院435区、参照現職・党派、合意情勢、現議会集計
- `src/data/content.ts`：ニュース項目、初回ガイド、論点レポートの差し替え可能な編集データ

- `public/data/house-2026-topo.json`：2026年下院435区の同梱TopoJSON
- `src/logic.ts`：構造検証、上院・下院の多数派計算

JavaScript、CSS、地図データは静的成果物へ同梱し、フォントもシステムフォントへ変更しました。閲覧時に外部APIやGoogle Fontsへ接続しません。出典リンクを利用者が押した場合のみ外部ページを開きます。

詳しい調査方法、論点分類、出典時点、制約は [RESEARCH_AND_METHOD.md](RESEARCH_AND_METHOD.md) を参照してください。上院100議席を再構築した工程は [DATA_VERIFICATION.md](DATA_VERIFICATION.md) に残しています。`CURRENT_STATE.md` と `TASK_01_RESULT.md` は各作成時点の監査履歴です。

## GitHub Pages

`vite.config.ts` は `base: '/us-midterms-2026/'`、workflowは `main` 更新時に `npm ci` → `npm test` → `npm run build` → Pages配備を行います。公開版が古い場合は、まずGitHub Actionsの最新配備が成功していることを確認し、画面上部の「最新版を再読み込み」を押してください。

## 更新上の制約

- 候補者・予備選結果・情勢・区割りは変化するため、公開前後に各資料の時点を再確認します。
- DE・RIの状態を更新するときは候補者の `ballotStage`、`contestStatus`、`candidateResearchStatus` を同時に更新します。
- 下院の参照現職は区割り変更後の情勢表ラベルであり、公式の現議会構成の集計には使いません。
- 候補者ごとの対中政策発言や支持団体は、現時点では構造化していません。大豆表は発言調査の優先順位を決める入口です。
- 特別選挙当選者の具体的な就任日は未定で、残任期の終了日と分けて表示します。
