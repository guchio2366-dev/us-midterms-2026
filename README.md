# 2026年米国中間選挙 — 中間選挙で変わる権力

[公開サイト](https://guchio2366-dev.github.io/us-midterms-2026/)では、2026年中間選挙を「どの議席が動くか」だけでなく、「結果がトランプ大統領の権限をどこまで制約するか」までつないで表示します。上院35選挙、下院435選挙区、議会権限、8つの論点、50州の地域背景に、重点州の調査・候補者・評価履歴・関連ニュースを重ねた静的Webアプリです。

> 基礎データ基準日：2026-09-09。研究モジュール更新日：2026-09-11。事実、外部機関の評価、編集上の解釈、利用者の仮定を分離して表示します。デラウェアは9月15日の予備選前、ロードアイランドは9月9日の開票確定前のスナップショットです。

## 画面の流れ

1. **ニュース**：公開済み12件を枠内で読みます。1ページ目は10件、2ページ目は2件で、下書き・レビュー中・撤回済みは件数にもページングにも入りません。カードの詳細は主画面を離れないパネルで開きます。
2. **権限**：ニュース直下の表をタイトルで開閉し、行のボタンから必要票をシミュレーションへ渡します。過去の上院採決は「多数派の一議席」と「個別政策の一票」を分ける例として示します。
3. **シミュレーション**：「権限から逆算」は独立した操作欄で制度上の必要票を確認します。「現在の選挙情勢」「投票前の議席構成」は地図直上の切替で表示します。100議席バーでは、薄色の非改選65議席と濃色の今回改選35議席を分けます。
4. **出典**：事実・評価・解釈・仮定と、それぞれの対象時点を確認します。

「初めて開いた方へ」と「8つの論点から選挙を見る」はヘッダーの独立パネルです。州詳細は、2024年の二大政党票を横棒、人口・GDP・情勢と必要な場合だけ特筆指標を表形式で示します。重点6州では、その下に選挙レポート、調査、機関別評価、関連ニュース、候補者名簿と候補者別調査を表示します。

関連ニュースの導線は双方向です。

- ニュース詳細から関連論点と関連州へ移動し、州詳細には「ニュースに戻る」を表示します。
- 重点選挙の州詳細には、その `electionId` に紐づく公開ニュースを最大4件表示します。
- 論点レポートには、その `issueId` に紐づく公開ニュースを最大5件表示します。
- ニュース詳細では `relatedCandidateIds` に一致する候補者名も表示します。

これらはURLルートではなく画面内状態による導線です。ニュースから論点へ移動した場合はパネル内の戻る履歴を、ニュースから州へ移動した場合は州詳細の「ニュースに戻る」を使います。関連候補者名は現時点では表示のみで、候補者カードへの独立ルートではありません。

## 投票調査の読み方

調査は見出しの二候補数字だけに縮約せず、母集団、標本数、実施期間、方法、スポンサー、設問、精度表記、回答区分を保持します。特に次のフィールドを使います。

| フィールド | 用途 |
| --- | --- |
| `studyId` | 同じ標本・同じ調査から得た複数集計を一つのstudyとして束ねる。未設定のレコードは各 `pollId` を一つのstudyとして扱う |
| `resultStage` | 初回値、leaner割当後、第1選択、移転・脱落過程、最終ラウンド等を区別する |
| `conditionLabel` | 「strict LV」「最終RCVラウンド」など、画面で読むべき条件を短く表示する |
| `completeness` | 公開資料で完全な回答内訳・方法を確認できないレコードを `partial` として明示する |
| `residualTreatment` | 合計差を `unreported`、`rounding`、`none` に分け、未掲載区分と丸め誤差を混同しない |

同一studyの複数段階は同じ囲みで表示します。州詳細では直近3studyを先に出し、それ以前を折りたたみます。異なる母集団や方法を混ぜた平均、調査間の連続的な支持移動、候補者別当選確率は計算しません。

## 重要な読み方

- **事実**：公式名簿、選挙当局、Census、FEC、BEA、USDA、調査原表、上院採決原票などの値です。
- **評価**：情勢評価機関によるSolid / Likely / Lean / Tilt / Toss Upです。勝率や確定結果ではありません。
- **解釈**：複数資料を結び付ける編集上の説明です。`observed`、`interpretation`、`hypothesis`を区別し、根拠箇所を `EvidenceRef` へ結びます。
- **仮定**：上院・下院シミュレーションで利用者が選ぶ結果です。予測ではありません。
- **地域指標**：政策への曝露や地域背景です。人口、産業、生産量、過去得票だけから投票理由や因果を断定しません。

評価履歴は `organization` ごとに日付順でつなぎます。異なる機関の分類は比較として並べますが、一つの時系列や平均にはしません。全35選挙を塗る地図の統一基準と、重点州の比較用評価履歴も別物です。

重点6州の比較用評価は25観測で、Cook 11、Inside Elections 10、Sabato 3、Fox News Power Rankings 1です。これらは全35選挙の地図に使うSabatoの統一基準を上書きしません。

## 議席数と権限の要点

- 下院は全435議席改選。通常の全員在席時、多数派は218。
- 上院は通常33＋特別2の一意な35議席が対象。残る65議席は今回の選挙では動きません。
- 上院運営多数派は51、または50＋副大統領の決裁票。通常法案の討論終結は原則60。
- 指名承認は上院の単純多数。条約同意と弾劾有罪は出席上院議員の3分の2。
- 下院は弾劾訴追を出席投票者の過半数で行えますが、罷免には上院の3分の2が必要。
- 大統領拒否権を覆すには両院それぞれ出席議員の3分の2。全員出席なら下院290、上院67。

研究データは画面ロジックへ直接書き込まず、安定IDで接続します。新しい資料は、Source → EvidenceRef → Poll / Brief / News等の順に追加し、`draft` または `reviewed` のまま検証してから `published` にします。公開UIは `published` だけを取得するため、調査中の差し替えが件数やページングへ漏れません。候補者名簿を変更するときは、候補者ID、調査結果、候補者brief、ニュースの関連候補IDを同時に検証します。

## 調査データの更新手順

1. 原資料を `Source` に登録し、公開・更新日、対象期間、取得日、内容確認日を記録します。
2. 表、設問、段落など実際に根拠とした箇所を `EvidenceRef` に切り出し、`observed` / `interpretation` / `hypothesis` を指定します。
3. 既存の `electionId`、`candidateId`、`issueId` を保ったまま、Poll、RatingObservation、Brief、News等を `draft` で追加します。同じ調査の別母集団・別集計段階は共通の `studyId` で束ねます。
4. `npm test` と `npx tsc --noEmit` で、重複ID、存在しない参照、別選挙の候補者混入、回答合計、州・論点・権限への関連付けを確認します。
5. 原資料との再照合後に `reviewed` を経て `published` へ変更します。訂正で旧ニュースを置き換える場合は `supersedesId` を使い、別調査を誤って上書き扱いにしません。
6. `npm run build` で静的成果物を生成し、`main` への反映後はGitHub Actionsのテスト・ビルド・Pages配備を確認します。

候補者の結合キーは表示名や出典URLではなく `candidateId` です。出典を差し替えるだけの更新でIDを変更せず、同姓候補も別IDのまま維持します。候補者本人を複数選挙にまたがって識別する用途は `personId` と分けています。

JavaScript、CSS、地図データは静的成果物へ同梱し、閲覧時に外部APIやGoogle Fontsへ接続しません。出典リンクを利用者が押した場合のみ外部ページを開きます。

詳しい調査方法、論点分類、出典時点、制約は [RESEARCH_AND_METHOD.md](RESEARCH_AND_METHOD.md) を参照してください。上院100議席を再構築した工程は [DATA_VERIFICATION.md](DATA_VERIFICATION.md) に残しています。`CURRENT_STATE.md` と `TASK_01_RESULT.md` は各作成時点の監査履歴です。

## 現時点の制約

- 実質的な選挙レポート、調査、候補者brief、評価履歴の第一波は6州です。他州は基礎名簿、統一情勢、州背景を表示しますが、同じ深さの調査済みとは扱いません。
- CandidateBriefは122候補中14候補です。重点6州の主要2候補に加え、IowaのThomas LaehnとAlaskaのDaniel J. Sullivan Jr.を収録し、それ以外は政策資料の追加待ちです。
- 収録調査は確認できた原表を優先した選択集合で、全調査の網羅、平均、モデル化された勝率ではありません。RV、LV、調査方法、設問、RCV段階を保ったまま比較します。
- 8論点のレポート枠はすべて公開されていますが、`completeness: partial`です。第一波の州事例を追加した段階で、全国的な結論ではありません。
- 現在の公開ニュース12件は、重点州の調査・候補交代・評価変更が中心です。重要な大統領発言、政策実施、デモ等を網羅するライブニュースサービスではありません。
- `HistoricalResult` は重点6州の2024年大統領選についてFECの候補者別確定票を収録し、二大政党票の割合を生票から計算します。他44州の棒グラフは既存の二候補差データを使うため、同じ粒度の生票データではありません。構造化された `PolicyPosition` の配列は現時点では空で、過去採決はRollCallVote、候補者方針はCandidateBrief内で表示しています。
- 権限から州を自動選択する経路、因果係数、当選確率、Xからの自動話題抽出は未実装です。現在の逆算欄は制度上の必要票と手動の議席仮定を扱います。
- 候補者・予備選結果・情勢・区割りは変化します。DE・RIを含む状態更新時は `ballotStage`、`contestStatus`、`candidateResearchStatus` と関連IDを同時に更新します。
- 下院の参照現職は区割り変更後の情勢表ラベルであり、公式の現議会構成の集計には使いません。
- 特別選挙当選者の具体的な就任日は未定で、残任期の終了日と分けて表示します。
- 関連ニュースの移動状態は共有可能なURLや再読み込み後の復元に対応していません。
- 自動検証はVitestによるデータ・純粋ロジックのテストです。ブラウザE2E、視覚回帰、スクリーンリーダーによる自動検証、lint、coverageの専用スクリプトはありません。
