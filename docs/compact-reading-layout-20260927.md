# 州別説明をコンパクトに、結論から読む配置（2026-09-27）

## 承認された構成

9月27日に承認された16:9の画像案を実装する。ヘッダー・ナビゲーションと冒頭概説は維持。「直近の更新」の本文幅を最大1280pxとし、文字・見出し・余白を詰める。位置図と8州の選択を同じ帯に置き、その下を州説明7：ニュース3へ分ける。州名と主要候補の下に結論を全幅で通し、その下を左の直接根拠／右の解釈に分ける。

## 内容と操作の契約

- 結論は既存の8州のfindingを使用。直接根拠は明示的なPoll IDまたは既存の一次根拠の表を参照し、隣の最新調査を誤って根拠に見せない。
- AKはDFP最終53対47、IAは同一調査のRVとstrict LVを直接表示。他の州は過去投票先別・同一調査内の別選挙・政党支持別・機関評価を、それぞれの性質に合わせた小さな表とする。部分集計に調査全体の人数・誤差を転用しない。
- 比較用調査は常時最大1件。別集計とそれ以前の調査は開閉してすべて残す。調査方法は各調査の下。
- 既存の週次解説は「州の論点・これまでの経緯」として開閉にまとめ、結論と解釈の読み順を妨げない。TXの過去比較も同じ場所から読める。
- ニュース・予定は最初の3件を表示し、一覧の開閉後は従来の10件単位のページ送りを維持。ニュース欄内の縦スクロールは廃止する。
- 「この州の結果を変えてみる」は明示操作時に選択州をシミュレーションへ引き継ぐ。当選仮定・保存案は変更しない。
- URLの州選択、ニュース・予定、記事履歴、キーボードでの州切替を維持する。

## 実装・画面幅

既存TypeScriptのDOM描画とSVGの小地図・支持率棒を再利用し、新しい描画ライブラリやデータ取得は追加しない。追加CSSは更新欄に限定。大画面では根拠・解釈を2列、狭い画面では結論→根拠→解釈→ニュースの順へ。小画面は本文15px以上、タッチ環境の操作対象44px以上を維持。長い州名・候補者名・文字拡大では折り返す。
