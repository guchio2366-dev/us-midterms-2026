# 州別ブリーフィングの密度と共通の読み方

## 目的と判断

対象は、日本語で米国選挙を追う読者。まず州の位置と対戦相手を把握し、支持率の数字と今週の意味を同時に読む。16:9のPCを基準に、文字を一律に縮小するのでなく、本文に着くまでの重複と余白を減らす。

利用者の指定は、候補者を州名の横、評価を州名の近くへ移すこと、地図と8州の操作欄の圧縮、読者へ提供する共通の見方を考えること。基点はmain `e2d34174b9d2703db8d5fa9e4c53b6b94554531a`。既存の公開権限に基づき実装・配備・表示確認まで進める。

## 表示

- 州別カードの英語の副見出しを省き、8州の分類内訳を「取り上げる理由」にまとめる。
- 広いカードでは位置図128pxと4列×2段の州選択。選択ボタンは56pxから44pxへ。地図の着色と選択下線を連動させる。狭いカードは小さな位置図と2列の州選択へ切り替える。
- 州名＋小さな評価バッジを左、両候補の氏名・党・現職表示を右に置く。狭いカードでは州名の直後に候補2列を置く。
- 本文は従来どおり、広いカードでは左が調査、右が解説。候補者を解説列から取り出し、本文の始点を上げる。本文サイズは維持する。
- 調査方法は各調査の下、候補者の詳細比較はカード全幅で開く。テキサスの過去比較表は残す。

## 「勝敗を読む視点」

全州共通の枠組みを「支持を固める／支持を広げる／支持を票にする」とし、各州では一つの具体的な問いと、既存資料から説明できることを初期表示する。共通3観点・詳しい根拠・次に確認するデータ・限界は欄内で開く。

| 州 | 主な観点 | 問い |
| --- | --- | --- |
| AK | 支持を票にする | 第一希望の後、誰へ票が移るか |
| IA | 支持を票にする | 投票者の想定で差が変わるか |
| ME | 支持を広げる | 政権と距離を取る姿勢が支持に届くか |
| MI | 支持を固める | 予備選後の結束が有権者にも届くか |
| NH | 支持を固める | 未定層の投票先がどう固まるか |
| NC | 支持を広げる | 州の党派傾向と候補者評価がどう違うか |
| OH | 支持を広げる | 共和党寄りの州でブラウンが誰に支持されるか |
| TX | 支持を固める | 共和党支持者がパクストンにまとまるか |

資料配列の最後を自動採用する旧「ここを見る」を廃止し、`src/data/briefing-lenses.ts`に選挙ID・論点・根拠・留保・出典を明示。政治家の行動を有権者の支持変化とは扱わない。NCの調査未収録、AKの再配分とIAの投票者想定の違いを明記。TX表の「今年はここを見る」は新欄へ統合する。

今回の分析は既存資料の編集であり、新しい世論調査の取得ではない。材料の確認日を進めず、配分・調査数値・保存案の形式を変更しない。資料を追加したときは、この欄の問い・読み取り・限界も同時に再点検する。根拠が増えるまでは未収録を維持し、自動で数字を補ったり監視完了を表示したりしない。
