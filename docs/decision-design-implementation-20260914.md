# 判断材料・表示・逆算の改善：実装記録

## 実装内容

1. **全国情勢の分母を統一**：非改選を含む民主党会派側46、共和党会派側48、未配分6を表示。未配分を接戦評価一致2・評価分裂4・評価資料不足0に分け、州地図・詳細・シミュレーターでも分類を明示する。民主党51、共和党51、共和党50の必要追加議席を別々に計算し、50の場合は副大統領の決裁条件を添える。
2. **記事を読者の判断順に整理**：人物と党派の文脈、事実、選挙上の意味、未確定事項を表示。分析記事の公開日と出来事の日付を区別する。州詳細のニュースを共通フィードに統合し、参考統計と補助資料を折りたたむ。ニューハンプシャー州の既存観測内容を州詳細と逆算に接続する。
3. **逆算を操作可能にする**：最大3案を分散させ、表示案の共通議席と制約上の必須議席を区別する。全候補議席の比較、議席ごとの固定、代替議席への交換、プレビュー・取消・適用・Undoを用意する。入力条件が変わったプレビューは無効化し、適用時にも再検証する。変更対象外の候補者選択と既存保存・共有機能を保つ。

既存の3列概要と初期説明を維持した。iPhoneのニュース欄は後続の利用者指定を優先し、約3件を表示する枠内スクロールを維持した。
