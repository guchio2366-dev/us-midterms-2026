# 8州の解説と情勢評価の割合

利用者の追加指示により、未配分の6州にIA・NCを追加する。前稿の「未配分6州のみ」を更新する。基点main: d0764ee52ecb4f901dd556395761c4a6283a7b71。

## 実装契約

- 対象は統合評価の未配分選挙＋IA-2・NC-2。8州を未配分8議席と誤認させず、導入で未配分6州と追加2州の違いを説明。将来の評価更新時も重複させない。
- 州名直下に1本の100%積み上げ横棒を表示する。仕事は「各機関の評価方向の構成を読むこと」。主経路は既存DOM/CSS、色は民主党寄り＝青、接戦＝灰、共和党寄り＝赤、判定不能＝淡灰。新ライブラリやアニメーションは不要。
- 元データは統合評価と同じ機関別スナップショット。分母は収録した機関数、各機関を等しく1件と数える。D／T／Rへ正規化し、未判定も分母から除外しない。百分率と機関数を常時表示し、勝率・得票率ではない旨を併記。原評価と機関別確認日は同じ場所の開閉内に残す。
- 同時描画は選択州の1本。横幅は親欄に追従、高さ14px。テキストを独立表示するため小区分も読める。データなしは空状態文、色やホバーに依存しない。表示機関が1つだけなら不足を明示。
- 州タブは広いPC欄（52rem以上）で8列1行、中間幅で4列2行、狭い欄で2列。ニュース・位置図・URLのbriefRace/newsRaceは既存の同じ選択状態に連動。議席計算や保存案は変更しない。
- IAは既存の公開研究、NCは既存の候補者名簿・選挙の論点を再利用する。日次観測6州と同等の調査済み表示にせず、既存の更新日と未収録を示す。分析日・資料確認日は進めない。
- 検証は8州の選定、2機関一致／分裂／判定不能／空データの割合、表示とニュース・地図の連動、PC・スマホと文字拡大。公開結果は実装PRへ記録。Safari実機は対象外。

## ローカル検証

126テスト成功、TypeScript・Viteの本番ビルド成功。未配分6議席を維持した8州の選定、全8州で位置図の1州強調、機関の一致・分裂・判定不能・不足・空データと割合を検証した。既存のJSチャンクサイズ警告は継続。公開後のブラウザ操作・寸法別確認とPagesコミットは実装PRに記録する。

公開確認でNCの既存基本文にシミュレーションへの誘導が残ることを検出。現在の会派と統合評価から議席の維持・奪取の意味を説明する文へ修正し、この欄だけで読めるようにした。未収録の週次解説・記事をあるようには表示しない。
