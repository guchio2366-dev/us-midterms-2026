# 冒頭の概説・議席グラフの実装記録

2026-09-13。設計書 `intro-overview-design-20260913.md` に基づく。

## 変更

- 目的の一文を常時表示し、制度・改選範囲の棒・争点6文・地図への入口を初回から表示する。旧ガイドパネルを廃止した。
- 上院65/35と下院435/435を中立色の横棒にし、全国要約の現職構成と必要配分も横棒に統一した。数値は基準データから算出し、非改選は淡色、改選は濃色とする。
- 民主党51は左から51%、共和党51は右から51%、下院218は218/435の位置。残り議席は中立色とし、予測と区別する。独立・空席・未確認を除外しない。
- 概説の手動開閉を独立したキーへ保存する。直接リンクで一時的に展開しても保存値を書き換えない。Class・特別選挙の詳細、院別の制約例、地図の読み方、更新情報を対応位置へ移動した。
- 既存のシナリオの保存形式、基準版、候補者ID、選挙データの確認日を維持した。
