# PC・16:9向け冒頭レイアウト

実施日：2026-09-22。利用者が生成画像の「左4：右6、左上に概説、左下に論点、右に上院3本の議席グラフ」を承認し、実装を許可。基点main：`61e20988f18cc5e336bbd96e013a745e19111888`。これは既存の[UX設計](ux-layout-design-20260915.md)の冒頭表示に関する後続仕様である。

## 情報を置く理由

| 常時表示 | 読者が判断できること | 圧縮・詳細化の方針 |
| --- | --- | --- |
| 上院・下院の現在議席と改選範囲 | 選挙前の出発点と今回動く範囲は何か | 同じ3列の表で比較。概説内の2本のグラフは右側と重複するため表へ変更 |
| 政策・予算・人事への作用 | なぜ議席の変化を見る必要があるか | 1文。院ごとの権能・採決条件は既存の「議席と権限」へ |
| 政権評価、地域差、候補者・投票参加 | 全国の情勢だけでは説明できない差を何から読むか | 3つの見出しと要点。元の解説・出典を開閉内に保存 |
| 暫定総計と基準日 | いつの評価で、どちら側に何議席置いているか | 民主・未配分・共和を同時表示。更新日と評価日を混同しない |
| 共通100議席尺度の3本のバー | 現在の配分と51議席への条件をどう比較するか | 非改選を同じ位置に固定。必要獲得数を明示。最小区分は棒を広げず説明で補う |
| 未配分の内訳・暫定の注意・50対50 | 接戦と評価分裂を混同していないか、51だけが運営条件なのか | 重要な留保は閉じずに残す。評価機関別35行・出典・確認日は開閉内 |

8論点の内容再設計・追加調査・一括校正、ニュース・地図・州詳細の配置変更は対象外。既存の8論点入口は詳細内に残す。選挙データ、評価計算、候補者、保存・共有URLは変更しない。

## 実装契約

- 主基準は1920×1080、補助は2560×1440、1366×768（CSS px）。実端末の解像度とOS倍率によるCSS幅は区別する。
- 冒頭とページ内ナビだけを画面幅−64px、最大2048pxへ拡張。既存の地図・ニュースなどの幅は変更しない。
- 1200px以上で40:60の2列。960〜1199pxは約43:57。959px以下は概説→上院情勢→論点へ縦並び。本文は15〜17px、注釈は12〜13pxを基本とする。
- 高さ固定、本文の省略、冒頭内スクロールを使わない。詳細を開いた時と文字拡大時は自然に縦へ伸びる。
- 同時表示するチャートは3本、合計13区分。既存DOM積み上げバーを再利用し、数値・幅・51の目標位置は実データから算出。Canvas、新しい描画依存、画像資産は不要。
- 棒の尺度は全て0〜100議席。民主の51は左から51%、共和の51は右から51%（左から49%）。淡色は非改選、濃色は今回改選。灰色の「未配分」と「配分未指定」はラベルと濃淡で区別。
- 棒の全区分をアクセシブル名に残し、値を色・ホバーだけに依存させない。6議席ラベルは常時表示。3議席未満の細い区分は無理に文字を詰めずアクセシブル名・内訳に残す。
- 任意の詳細はネイティブdetails。制度・論点の既存オーバーレイを維持。概説全体を閉じる旧操作・旧保存設定は廃止し、表と要点を常時表示する。議席案の保存設定は変更しない。
- 単純な表の照合と3本の構成比較として設計。表示を`src/ui/overview.ts`、範囲限定CSSを`src/ui/overview.css`へ分離し、既存計算処理を再利用。ローカルで数値・アクセシビリティ・意味の再点検を実施し、サブエージェントは使用していない。
