# 接戦州の解説とニュースを同じ場所で読む

利用者が画像案を承認し、実装・公開を指示。基点mainは `0d2d41155a9b78551eb1ed8603991d876e173a07`。既存の冒頭1440px・60:40を保ち、「直近の更新」は1200px以上で2:1、960〜1199pxは3:2、959px以下は縦並びとする。

## 読む順序

1. 制度解説の最初の文の直後に「Class制度・特別選挙とは」を文中リンクとして置く。
2. 上院の配分欄の末尾で、現在は両党とも51議席に届かず6議席が未配分であることを説明し、州別解説へつなぐ。数と過半数の状態は既存の統合評価から算出する。
3. 「過半数の行方を左右する6州」の上部タブで選択。対象は冒頭と同じ未配分議席（接戦・評価分裂・資料不足）から生成し、現在はAK・ME・MI・NH・OH特別・TX。従来のIA・NCはこの特集から外すが、地図・研究・シミュレーションには残す。
4. 同じ欄に主要候補、今週の焦点、判断材料を表示。詳説を開くと経緯・不確かさ・根拠・候補者比較・次に確認する点を読める。下のシミュレーションへは移動しない。
5. 欄の下部に同梱の50州境界を再利用した幅240px以下の位置図。選択した1州のみ金色、その他は灰色。投票傾向の色ではない。アラスカ・ハワイの位置・縮尺の調整を注記。
6. 右側の最近のニュース・今後の予定は選択州に連動。「全国」で全件へ、「この州」で選択州へ戻す。州を切り替えると州別表示へ戻り、両タブのページとスクロール位置をリセットする。

## 機能と既存データ

- 新たな政治分析や数値を作らず、最新mainの公開済みRaceObservationと記事・予定を再利用する。確認しただけで分析更新日を進めない。
- 候補者比較の見出しIDにbriefing接頭辞を使い、下の州詳細を同時に開いてもIDが重複しない。読む欄には当選仮定の選択を入れない。
- 記事は既存パネルで背景・根拠を読み、閉じると元のニュース欄へ戻る。予定日経過・結果確認待ち等の区別を維持。
- newsRace・newsTabに加え、全国表示をnewsScope=all、選択タブをbriefRaceで再現。既存の議席保存・共有パラメータsを維持する。
- 欄の下に「議席配分をシミュレーションする」を独立した入口として置く。説明を読む操作と議席の仮定を変える操作を区別する。
- 対象州は評価更新時に変わり得る。詳説の未収録時は確認中と表示し、他州の文章を流用しない。

## 検証

ローカルの124テストとTypeScript・Viteビルド成功。6州と未配分の一致、資料不足への追従、実際の州境データで1州だけを強調すること、比較IDの重複回避、記事・予定の州別絞込み、制度リンクと導入文を検証。既存のJSチャンクサイズ警告は継続。公開後の画面・操作検証と対象コミットの配備結果は実装PRへ追記する。実機Safariの確認は含めない。
