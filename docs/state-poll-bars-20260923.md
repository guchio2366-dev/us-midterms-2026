# 州別グラフを調査ごとの候補者支持率へ訂正

> 後続変更：州名横への候補者移動、州選択の圧縮、共通の読み方は[2026-09-24の改訂](compact-state-briefing-20260924.md)を参照。以下は作成時点の記録。

利用者の「割合」の意図を取り違えた機関数のグラフを撤去する。8州・地図・ニュース・本文配置は利用者の追加発言「ほかはめちゃくちゃいい」に従い維持。基点はc01327b02a5271380f5e4708306987f68efa55c7。

- 読者の問い：各調査では誰が何％か。各調査を別々の横棒として同じ幅に上下配置。収録済みの公開調査を実施日の新しい順に2調査常時表示し、過去分もその場で開く。
- 対象・人数・日付・機関・スポンサー・投票段階と精度を併記。平均・勝率・支持移動へ変換しない。元の候補者名と小数値を保持する。
- 同じstudyIdのRV/LV別集計、未定者割当後、順位投票の段階違いは同じ調査の補足として開閉。二つの独立調査と数えない。最終RCVだけを収録した調査は段階・部分公開を常時表示。
- Dは青、Rは赤、未定はベージュ、その他は緑灰、内訳未掲載は淡灰。全区分に文字と数値を併記し、ホバー不要。内訳未掲載を未定や候補者支持へ配分しない。
- 棒は100を基準とし、整数丸め等で合計が100超のときだけ公表値の合計を視覚上の分母とする。ラベルの数値は公表値のまま、合計と丸めを明記。方法・設問・注記・原資料リンクは調査ごとに開閉。
- 既存の構造化Pollを再利用。NH・NCのPollは未収録であり空状態を表示。ニュース本文には構造化Pollより新しい調査への言及があるため、「最新の全調査」ではなく「収録済み」と明記。データの新規調査・再確認や分析日の更新は行わない。
- DOM/CSSで2本を通常表示、補足の棒は閉じたdetails内。14px高、可変幅、ラベル折返し、同じ順序でスマホへ対応。州選択とURLは既存の状態を利用。依存ライブラリ追加なし。
- 検証：実データの独立調査選択、公開状態、割合と丸め、未掲載残余、投票段階、空データ、画面で2調査同時表示・州切替・開閉・PC／スマホを確認。公開コミットとQAはPRへ記録する。

## 省スペース配置への後続改訂

利用者の追加指定「解説は論点の解説。調査の解説は調査の下」に対応する。基点はPR #23の8287e8b119ca52424ae749f926566b0c2c9cf900。

- 州別カード内を二分し、左に主要候補・今週の論点・判断材料、右に小さな調査別支持率グラフを上下に配置する。外側のニュース欄・州選択・位置図は維持。
- グラフの直下に候補者別数値、実施期間・調査対象・人数・集計条件・精度を置く。方法・設問・出典はその下で開閉する。
- 論点の詳説と候補者比較は二列の下でカード全幅を使って開く。
- カード内容幅40rem未満は解説→調査の一列。固定高・文字の切り詰めは使わない。文字拡大でも情報を欠落させない。
- 収録値、丸め処理、投票段階・別集計、NH/NCの未収録表示、8州、ニュース連動は変更しない。
- 既存テスト・本番ビルドおよび公開後のPC／スマホ・文字拡大・州切替・開閉を確認し、結果は実装PRに記録する。

## 州選択と位置図の一体化

PR #25のb4592838732265fb28a0b3d34f47309b38851103を基点とし、相談後の実装・公開指示に対応。

- 州別カード上部に位置図と州選択を一体配置。PCでは地図180pxを左、8州を4列×2段で右に置く。ボタンは枠を外し、選択中だけ薄い背景と下線で強調。情勢ラベルとキーボード操作は維持する。
- 地図の着色は選択州のみ。州名、着色の意味、アラスカ・ハワイの調整注記を併記。下部の位置図は撤去して重複させない。
- 州選択・URLでの初期選択・履歴移動・地理データ読込後のすべてで、地図とキャプションを現在の選択州に同期する。
- カード内容幅38rem未満では地図と注記を横に並べ、その下に2列×4段の州選択。文字の切詰めや横スクロールは使わない。
- 下段は左グラフ／右論点の解説を維持。調査説明は各グラフ直下、候補者詳説は全幅の開閉。選択州のニュース連動も維持する。
- 既存テスト・本番ビルドと公開ChromeのPC／スマホ／文字拡大、8州の地図・解説・ニュース・URL連動を検証。公開結果は実装PRに記録する。
