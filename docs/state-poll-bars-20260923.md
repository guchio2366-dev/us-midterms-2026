# 州別グラフを調査ごとの候補者支持率へ訂正

利用者の「割合」の意図を取り違えた機関数のグラフを撤去する。8州・地図・ニュース・本文配置は利用者の追加発言「ほかはめちゃくちゃいい」に従い維持。基点はc01327b02a5271380f5e4708306987f68efa55c7。

- 読者の問い：各調査では誰が何％か。各調査を別々の横棒として同じ幅に上下配置。収録済みの公開調査を実施日の新しい順に2調査常時表示し、過去分もその場で開く。
- 対象・人数・日付・機関・スポンサー・投票段階と精度を併記。平均・勝率・支持移動へ変換しない。元の候補者名と小数値を保持する。
- 同じstudyIdのRV/LV別集計、未定者割当後、順位投票の段階違いは同じ調査の補足として開閉。二つの独立調査と数えない。最終RCVだけを収録した調査は段階・部分公開を常時表示。
- Dは青、Rは赤、未定はベージュ、その他は緑灰、内訳未掲載は淡灰。全区分に文字と数値を併記し、ホバー不要。内訳未掲載を未定や候補者支持へ配分しない。
- 棒は100を基準とし、整数丸め等で合計が100超のときだけ公表値の合計を視覚上の分母とする。ラベルの数値は公表値のまま、合計と丸めを明記。方法・設問・注記・原資料リンクは調査ごとに開閉。
- 既存の構造化Pollを再利用。NH・NCのPollは未収録であり空状態を表示。ニュース本文には構造化Pollより新しい調査への言及があるため、「最新の全調査」ではなく「収録済み」と明記。データの新規調査・再確認や分析日の更新は行わない。
- DOM/CSSで2本を通常表示、補足の棒は閉じたdetails内。14px高、可変幅、ラベル折返し、同じ順序でスマホへ対応。州選択とURLは既存の状態を利用。依存ライブラリ追加なし。
- 検証：実データの独立調査選択、公開状態、割合と丸め、未掲載残余、投票段階、空データ、画面で2調査同時表示・州切替・開閉・PC／スマホを確認。公開コミットとQAはPRへ記録する。
