## 利用者との合意

「何を確認すべきか」より先に、現在の資料から言える有用な結果を一文で示す。続いて数字・制度などの根拠を示す。断定を強めるために因果関係や支持移動を作らない。

## 実装

- `briefing-lenses.ts` の8州を全面改稿し、`finding` を最初の見出し、`evidence` を常時表示とした。制度や集計対象など、結論を理解するのに必要な条件は隠さない。
- 右の解説列は「結論と根拠 → 今週の焦点 → TXの過去比較」。問い、詳しい読み取り、限界、次の確認、共通3観点、出典箇所は折り畳み。
- 位置図・候補者・調査グラフ・関連ニュースの既存配置を維持。新しい党派別数値を州全体の支持率グラフには混ぜない。
- 追加原表と根拠箇所を `briefing-lens-sources.ts` に収録し、共通のSource/EvidenceRef台帳へ接続。根拠リンクは箇所と確認日を表示する。
