# テキサスの過去調査から読む解説

## 依頼と範囲
8州の過去調査検証を受け、「テキサスだけやってみて」という依頼に対応。
2026年の既存解説に、2024年の同一調査と公式結果を比較する小さな表を追加した。
変更の基点はmain `cbfff686bfdf1cde76ec7c91df28811f31c2614d`。

## 読む順序と実装
- 既存の候補者・今週の焦点・判断材料に続けて、過去の比較を右側の解説列へ表示。
- 見出し「共和党が強い州でも、候補者によって差は変わる」→2024年の比較表→今年は自党支持と無党派への広がりを見る、の順。
- 2024年、共和党のリード幅、ポイント単位を表の直上に明記。2026年の支持率グラフとは区別する。
- 数値はHTMLの表で常時表示。色だけに意味を持たせず、caption・列見出し・行見出しを付ける。説明と出典はネイティブdetailsで開閉。
- 既存のcontainer queryに従い、狭い画面では解説→調査の順。幅を固定せず、文字は折り返す。
- 表示部品は`src/ui/texas-poll-context.ts`、数字・出典は`src/data/texas-poll-context.ts`。研究の共通出典一覧にも登録。
- テキサスのelectionIdだけを対象に1件表示。州切替時は既存の再描画に従う。URL・保存形式・議席配分・現行Pollには変更なし。追加の通信・ライブラリ・描画エンジンなし。

## 数字と解釈
Emersonの2024年10月18〜21日調査、LV815人。大統領R53/D46、上院R48/D47。同一標本の2設問。
州公式結果の保存PDFを用い、各選挙の全有効票で差を計算する。

|2024年の共和党候補のリード幅|Emerson調査|実結果|
|---|---:|---:|
|大統領選|7.0|13.7|
|上院選|1.0|8.5|
|上院で縮まった差|6.0|5.2|

最後の行は候補間差の差であり、候補本人の得票率上乗せや分割投票者の割合ではない。
相対差の傾向が近かった一例であり、一般的な精度保証、調査方式の格付け、2026年支持率の補正には使わない。
調査終了は投票15日前。候補者・第三候補・投票者構成・情勢変化を分離した因果推定ではない。
