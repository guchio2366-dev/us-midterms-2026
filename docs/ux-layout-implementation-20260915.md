# 概説・直近の更新・州詳細のUX改善 実装記録

実施日：2026年9月15日（日本時間）。対象設計：[概説・直近の更新・州詳細のUX改善設計書](ux-layout-design-20260915.md)。

## 実装した内容

- 冒頭を、左側の現在議席・改選範囲・主な論点と、右側の上院情勢・51議席への配分例に再構成した。暫定配分は民主・共和・未配分の合計を先に表示し、算出方法・50対50の条件・35選挙の内訳・出典は開閉欄へまとめた。
- 旧「全国情勢を30秒で確認」を「直近の更新」へ改めた。注目8選挙は英語州名順のタブで切り替え、Toss Up、評価分裂、評価不足を区別した。タブ切替はニュースの絞込みや議席仮定を変更しない。
- ニュース・予定を注目州と横並びにし、カードの縦縮小を止めた。見出しは全文表示、要約は既存の2行省略を維持し、一覧だけをスクロールする。「予定・予定」となる重複表示を解消した。
- iPad横の上院地図と州詳細を1対1にした。地図、凡例、地図下の説明を含む左側の自然高を監視し、右側の詳細枠を同じ高さに合わせる。1列時は固定高と内部スクロールを解除する。
- 詳説済み州の主要2候補を、同じ比較項目の左右に常時表示する。経歴・地元、政策・採決・発言、政党・トランプとの関係を初期表示し、実績への評価・批判と有権者の受け止めは両候補まとめて開く。
- 地図・州詳細の上に「あなたの仮定」を表示し、民主・共和・未配分・その他・合計、議席バー、直近の増減、既存Undoへの入口をまとめた。
- 「議席と権限」は法律・予算、人事、調査・監督の要点を先に表示し、既存8項目、採決例、出典を一つの開閉欄へ移した。
- `#updates`をページ内移動へ追加し、既存の`#overview`、`#national-overview`、`#news`、`#powers`、`#simulator`、`#map-heading`、`#sources`、`#issues`とURLパラメーターの扱いを維持した。

| ファイル | 変更 |

情勢集計、議席の基準版、候補者・州・ニュースのデータ、保存形式、共有URL形式は変更していない。8論点の内容再設計、個別共有、詳細文の一括校正も保留を維持した。
