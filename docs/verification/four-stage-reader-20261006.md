# 2026-10-06：4段階の読者導線

## 範囲と合意

仕組み → 議席配分 → 州と候補者 → 見通しの順で読む。争点や政策は独立した必須章にせず、州・候補者の比較の文脈から読む。見た目は既存の色・字体・PC左端目次を継承し、Atlas風の別デザインにはしない。

- 01：改選対象と上下院の役割。政権への政治的評価と制度上の信任投票、州の候補者選定と個人の推薦、大統領候補を選ぶ全国党大会を区別する。
- 02：現在構成、既存の暫定配分と多数派の条件。党派多数と個々の政策票の違いを短く説明し、権限・採決条件と任意シミュレーションを接続する。
- 03：12州の既存の調査・地域事情・候補者比較・ニュース・予定。医療と関税の事例、8論点、候補者の具体的政策・採決記録は開閉欄や既存の候補者ボタンから読む。
- 04：既存データから現在評価、不確実性、次に確認する予定を表示する。新たな予測値や勝敗の確定は加えない。

新しい制度説明はUSAGov、FEC、米国立公文書館、上下院の公式資料で確認した。出典リンクと確認日は `src/ui/reader-context.ts` に併記する。現在の候補者推薦や政策一致を推測で追加しない。
