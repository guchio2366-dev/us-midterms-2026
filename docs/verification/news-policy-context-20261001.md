# ニュース・州から政策検討へ（2026-10-01）

ニュースの判断材料と州の見通しを読み、その資料と関連州を保ったまま政策欄へ進める。政策を特定できない調査ニュースでは、テーマと政策版を読者が選ぶ。候補者選択や議席配分は、入口を押すだけでは変わらない。

## 文脈の引継ぎ

- 記事・分析更新・予定の詳細へ「このニュースを材料に考える」、10州の解説へ「この州の材料から政策を考える」を追加。既存の下部シミュレータへ進む入口は維持する。
- `PolicyReadingContext`は読書中の一時状態で、シナリオへ保存・共有しない。公開レコードの州・論点・出典参照から解決し、題名や支持率から政策を推測しない。具体政策版の自動選択は直接のfeed参照に限る。
- 読んでいた資料を政策欄の先頭へ表示し、関連する州の資料を次に読む。原資料の公表日、サイト掲載・更新日、根拠の確認日は区別し、原典ごとの日時と対象期間を開閉欄に保持する。
- 記事へ明示的に接続された公開分析更新があれば、その州・根拠・出典参照を引き継ぐ。記事の戻り先では州フィルタ・タブ・ページ・記事と一覧のスクロール位置を維持する。
- 案の当選仮定、会派、100議席の保存基準、理由・根拠snapshot、Undo、2案比較の選択政策、個人メモの共有除外は既存契約を維持する。AARP等の未再照合資料や新しい政策調査は今回追加していない。

## 検証

Windows / Node 24.19.0で23ファイル295テストとTypeScript・Vite本番ビルドを確認。追加テストは、対象と方法が異なるPollの区別、公開IDと根拠整合、直接feedだけの政策版選択、未選択の表示、元の案を変えない読書状態、出典とサイト日時の区別を対象とする。

ユーザーPCの専用Chrome 154（個人プロファイルと分離）で1180×757と390×844を操作した。NC/MIの記事から正しい選挙と先頭資料へ進み、政策未特定のまま戻れること、10州の入口、作業案のバイト保持、直前の実変更のUndo、NC HPUとMI Foxの直接グラフを確認。既存の保存2案比較・理由の陳腐化・共有メモ除外と独立旧Brown共有fixtureのD47/R47/未配分6・旧方式通知・作業案非上書きも確認した。390pxで横スクロールの増加はない。

ブラウザ履歴の戻る/進むで記事位置を保持し、ニュース→州詳細→政策の経路でも元の記事と州を維持することを確認した。CI、Pages配備、公開コミット・成果物一致、公開後の画面判定は当該PRへ記録し、ローカル検証から公開済みとは扱わない。
