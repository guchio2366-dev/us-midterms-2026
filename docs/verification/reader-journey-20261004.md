# 2026-10-04：背景を読んでから当落と政策を考える構成

## 目的と対象

利用者が承認した順序と最新原稿を基本に、冒頭で全体を理解した後、仕組み→争点→州と候補者→議席配分→政策への影響→見通しを読む構成にする。背景や候補者の違いを説明する前に、当選者や共通前提の入力を求めない。

基点はmain `d0a066ff391e298758696c84c90105e00e411343`。10月4日の日次更新、情勢の根拠、候補者ID、引用、資料時点を保全する。参照画像のα州・A/B候補・概念議席は架空例であり、実サイトの事実や予測に転用しない。

最新の冒頭文と6節の導入文は [reader-journey.ts](../../src/data/reader-journey.ts) を正とする。旧画像内のキャッチコピーや以前の長文拡張稿へ戻さない。今回の変更は読解体験と配置の更新であり、新しい予測モデルや政策調査の追加ではない。

PCは左端の固定目次に01〜06を表示し、現在の節を強調する。狭い画面では横方向の目次へ切り替える。各節の説明と根拠を保ち、詳細・出典や任意操作は開閉で整理する。全説明を一画面へ押し込むための字体縮小は行わない。

03の「収録した調査から読めること」は、その対象調査の解釈を示す。過去調査の結果を現在の勝敗の確定的な結論へ置き換えず、対象期間・集計段階・最新資料との違いを保つ。主要候補の読み取り用要約は、当選者の指定や保存案の変更を伴わない。

## 保持する契約

- 上院100議席・今回35選挙と、下院435選挙区を別に扱う。現在の上院暫定配分は既存計算によるD43・R45・未配分12。双方が同党方向のLikely／Safe／Solidの場合だけ配分する基準を変更しない。
- 弱い優勢、接戦、機関間の評価分裂、資料不足を区別する。未配分を一律にToss Upと表示しない。評価基準日、評価の確認日、記事公表日、調査期間を混同しない。
- 既存DOMを移設し、仮定・保存・共有のロジックやデータ形式を置き換えない。旧保存案の100議席の基準、当落指定、理由、個人メモを、新しい基準へ黙って再計算・上書きしない。
- 旧hash（`#overview`、`#national-overview`、`#updates`、`#news`、`#policy-workbench`、`#powers`、`#simulator`、`#scenario-manager`、`#sources`、`#issues`等）と記事・州・共有案のqueryを保持する。旧入口に必要な開閉だけを開き、読む操作で保存設定を書き換えない。
- 06は現在の情勢評価を表示し、利用者案とは区別する。公開済みの既存更新と予定だけを使い、予定日を過ぎただけで実施済みにしない。記事詳細へは既存のフィードキーで接続する。
- 政策の版、過去の採決、本人の公約、行動の範囲、確認日と未確認事項を保持する。H.R.1全体への票を個別条項の賛否へ換算しない。候補者の未調査を反対・無関心と表示しない。MN/NE等の材料を推測で補完しない。
- 医療・関税の候補者記録は調査済み範囲だけを示す。全100議員の賛成数、当選確率、成立確率を生成しない。両院、大統領、討論終結等の条件を党の議席数と分けて扱う。
- 個人メモは共有URLへ送出しない。説明を読むだけで当落や保存案を変更しない。
