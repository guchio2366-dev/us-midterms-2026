## 配分方式

全35選挙についてSabatoとInside Electionsの党方向が一致し、両方がLikely／Safe／Solidの場合だけ党派側に置く。一方でもLean／Tilt、tossup、方向不一致、不足なら未配分。多数決で方向を決めない。強さを平均しない。方式は `unanimous-likely-or-stronger-v2`、snapshotは `senate-ratings-2026-09-30-strong-agreement-v2`。

非改選D34・R31は従来通り。改選をD10・R15に暫定配分し、全体D44・R46・未配分10になる。旧D46・R47・未配分7からNC・GA・KSが未配分へ移る。未配分はAK、GA、IA、KS、ME、MI、NC、NH、OH特別、TX。重点州は従来の8州へGA・KSを加えた10州で、現在は未配分の10州と一致する。

原評価のToss Upとサイトの未配分を区別する。弱い優勢3・接戦2・方向分裂5。地図の中立色には弱い優勢を含み、「Toss Up」と一括表示しない。元の35選挙×2機関の値と確認日はそのまま内訳で読める。議席棒、新規シミュレータ、逆算の入口にも同じ配分を使う。必要配分の例と確率・予測は区別する。
